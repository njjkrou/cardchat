## これは何か

CardChat は、AI キャラクターとのロールプレイを前提に作られた**運営可能な**プラットフォームです。
ユーザーはキャラクターカードを作成・インポートし、長期的な会話を楽しみます。
プラットフォーム側はモデル接続、コンテキスト組み立て、長期記憶、コンテンツ安全、コイン課金を担い、
管理者は管理画面から審査・設定・運営を行います。

難しい部分はすべてサーバー側にあります。

- **コンテキスト設計** — キャラクターカード、ワールドブック、プリセット、正規表現スクリプト、
  引用返信、記憶ブロックをトークン予算内で組み立てる
- **長期記憶** — 階層圧縮・事実抽出・ハイブリッド検索により、数十ターン後でも覚えている
- **マルチテナント課金** — プラットフォームキーとユーザー自身のキーの併用、usage ベースの正確な精算、
  サブスクリプションとコインの共存
- **運営性** — 審査、注文、台帳、サブスク、お知らせ、プラットフォーム設定

> 本リポジトリは**フロントエンドのビルド成果物（難読化済み）のみ**を収録しています。
> バックエンドのソースは公開していません。以下の機能説明はフロント・バックエンド全体を扱います。

## アーキテクチャ

<p align="center">
  <img src="docs/architecture.svg" alt="アーキテクチャ" width="100%">
</p>

| レイヤー | 採用技術 |
|---|---|
| フロントエンド | Vue 3 · TypeScript · Vite · SSE ストリーミング |
| バックエンド | Node.js（22/24）· Express · TypeScript |
| データベース | SQLite（WAL）· `node:sqlite` · FTS5 全文検索（trigram） |
| モデル接続 | OpenAI 互換ゲートウェイ、ストリーミング＋非ストリーミングへフォールバック |
| デプロイ | Docker Compose（server + web）· Nginx リバースプロキシ |

設計上の判断：

- **単一プロセス + SQLite** — 中小規模なら Redis/MySQL の運用が不要。WAL で同時读写を処理し、バックアップはファイルコピー
- **キーはサーバー側に保持** — フロントは秘密情報を持たない。ユーザーが自分のキーを入れればコイン不要
- **同期ストリーミング＋非同期記憶** — 返信は即時、要約と事実抽出はバックグラウンド

### 3. 長期記憶システム（中核）

会話が長くなるほどコンテキストは高コストになります。記憶を層に分け、固定トークン予算で最大限の記憶を確保します。

| 層 | 役割 | コスト |
|---|---|---|
| **L1 作業記憶** | トークン予算＋件数上限で直近の原文を切り出す | 毎ターン固定 |
| **L2 区間要約** | 30 件または 6,000 字ごとに要約を生成、以後再計算しない | 区間ごとに 1 回 |
| **L3 事実カード** | 要約から身元／好み／関係／出来事を抽出し重複統合 | L2 と同時 |
| **検索注入** | 現在の入力でキーワード検索し、関連する過去を注入 | 毎ターン 1 クエリ |

その他：

- **切り詰めがなければ注入しない** — 予算内に収まるなら記憶ブロックを付けない
- **文単位のキーワード抽選** — 長文 1 文が枠を独占せず、「ピーナッツアレルギー」等の短語も拾える
- **事実の重複排除** — 2-gram 類似度＋最長共通部分列で統合
- **会話ごとのオン／オフ** — 既定オン、チャット画面から変更可
- **要約失敗は保存しない** — ポインタを進めず次回再試行

実測：長文返信の会話で **prompt トークン約 35% 削減**、かつウィンドウ外の事実を正しく想起。

## バックエンドの役割

ソースは非公開ですが、実際に担っている処理を記載します。

1. **認証とテナント分離** — JWT、bcrypt、キャプチャ、レート制限、全クエリに `user_id` 条件。
2. **モデル接続層** — OpenAI 互換、プラットフォームキー／ユーザーキー、ストリーミング失敗時のフォールバック、
   HTTP 200 内にエラー文を返すゲートウェイへの内容レベル防御。
3. **Prompt エンジン** — システム→カード→ワールドブック→プリセット→ペルソナ→記憶→履歴→入力、
   SillyTavern マクロ、引用展開、トークン予算。
4. **記憶サービス** — 定期スキャン、専用要約モデル、FTS5 trigram＋LIKE の併用、文字数予算で注入。
5. **課金** — usage ベースの正確なコイン計算、冪等台帳、サブスク特典、残高チェックをメッセージ保存前に実施。
6. **自動メッセージ** — 放置された会話へ自発的に送信、課金と記憶も通常どおり、空返信は防止。
7. **安全** — キーワード／ルール審査、アップロード検証、公開内容の人手審査、通報対応。
8. **決済** — 注文作成、署名検証、非同期コールバック、状態遷移。
9. **管理 API** — 32 エンドポイント。

## フロントエンドコードについて

- `web/` は**本番ビルド**です。source map とコメントを除去し、識別子を短縮、さらに文字列配列エンコードと
  制御フロー難読化を適用しています
- 難読化は成果物のみに適用し、起動・ルーティング・描画は動作確認済みです
- Vue の元ソース、バックエンド、DB スキーマ、運営設定は**含まれません**
- 二次開発・プライベートデプロイ・機能追加のご相談は作者まで
